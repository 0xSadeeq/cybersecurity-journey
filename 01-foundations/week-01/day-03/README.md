# Week 1 — Day 3: Authentication, Authorization & Access Control

## Objective

Understand the difference between authentication and authorization, and learn how MFA, access control, and least privilege protect systems.

## Concepts Learned

### Authentication

Authentication verifies the identity of a user.

Examples:
- Password
- PIN
- Fingerprint
- Security key
- Multi-factor authentication (MFA)

**Question answered:** Who are you?

### Authorization

Authorization determines what an authenticated user is allowed to access or do.

**Question answered:** What are you allowed to do?

### Access Control

Access control uses rules and mechanisms to determine which users can access specific resources.

### Multi-Factor Authentication (MFA)

MFA requires more than one authentication factor.

Example:

Password + verification code

MFA can help protect an account even when an attacker obtains the user's password.

### Principle of Least Privilege

Users should receive only the permissions necessary to perform their job.

## Scenario Analysis

A company employee entered their credentials into a phishing website. An attacker obtained the password but could not access the company's system because MFA was enabled.

### Attack

The attacker exploited human weakness through phishing.

### Security Control

MFA provided an additional authentication requirement.

### Important Lesson

A stolen password does not necessarily mean an attacker can access an account when additional security controls are implemented.

## Key Takeaways

- Authentication verifies identity.
- Authorization determines permissions.
- MFA adds additional authentication protection.
- Access control limits access to resources.
- Least privilege reduces unnecessary access.
